# Color Scheme Switcher

Click the colored buttons to change the page background color.

## What It Does

- 4 colored buttons (grey, white, blue, yellow)
- Click a button to change the background color
- Simple and easy to use

## Files

- `index.html` - The page layout
- `style.css` - The colors and design
- `script.js` - Makes the buttons work
- `README.md` - This file

## How to Use

1. Open `index.html` in a browser
2. Click any colored button
3. Background color changes

## Colors

- Grey button → grey background
- White button → white background
- Blue button → light blue background
- Yellow button → yellow background

## Tools Used

- **HTML5**: Document structure
- **CSS3**: Styling and layout
- **JavaScript (ES5)**: Event handling and DOM manipulation
